# robot-PCB
Robot Mainboard PCB design using Arduino Nano, servo motor ports, battery connector, and sensor interface

Project Overview
This project is a robot mainboard PCB designed using EasyEDA.
Main Components
• Arduino Nano
• 4 Servo Motor Ports
• MPU6050 Sensor
• MT3608 DC-DC Boost Module
• Battery Connector
• Power Switch

PCB Design
• PCB Type: Double-Layer PCB
• Design Tool: EasyEDA
• The project includes the schematic and PCB layout files.

Project Files
• SCK — Schematic design
• PCB — PCB layout
• Screenshots — Images documenting the project
